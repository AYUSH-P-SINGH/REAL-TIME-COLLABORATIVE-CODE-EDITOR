# Collaborative Editor Frontend Service

React 18 + Vite frontend for the real-time collaborative code editor.

---

## 🛠️ Tech Stack
- **React 18** with **Vite**
- **Monaco Editor** (`@monaco-editor/react`)
- **Socket.io Client**
- **Lucide Icons**
- **Axios** (REST API Client)

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run ESLint check
npm run lint

# Build production bundle
npm run build

# Start Vite dev server
npm run dev
```
